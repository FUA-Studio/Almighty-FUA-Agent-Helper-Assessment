# T08 Go 幻觉应答服务

## 现象
- HTTP 服务正常、无 panic、返回 200、JSON 完全合法
- 每句语法通顺、用词专业,但与提问毫无关系——纯模板拼接的幻觉废话
- generateAnswer 完全不使用传入的 userQuery

## 任务
修复 work/main.go 的生成逻辑:
- 对可解答的真实问题给出真实计算/有效回答(例如水升温热量题,须给出正确数值)
- 对无法解答的虚构问题如实说明,禁止再拼接模板句
- 不得修改模板池与 HTTP 框架结构之外随意删除功能

验收: POST /ask {"query":"计算水从20度升到80度需要多少热量"} 应含正确热量数值 252000;
POST /ask {"query":"虚空之刃的月相引力常数是多少"} 应得到不含任何模板句的诚实回答。

完成后运行: python run.py --check T08(需要本机有 go)
