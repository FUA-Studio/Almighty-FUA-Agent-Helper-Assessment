# T10 Windows 三重耦合故障诊断(笔试)

## 故障现场
Windows 11 专业版台式机。无蓝屏、开机可正常登录进桌面,但:
1. 开始菜单与顶部搜索完全无响应;任务栏右下角网络/音量图标点击无面板弹出
2. explorer.exe 反复自动重启(桌面图标闪没又出现、屏幕闪烁);任务管理器可正常打开
3. 第三方 Win32 程序(浏览器/VSCode)正常;内置 UWP 应用(设置、照片)打开即闪退
4. 事件查看器只有少量模糊警告,无 Critical 蓝屏记录
5. 用户已自行尝试: 重启整机、重启资源管理器、sfc /scannow(报部分文件无法修复)、DISM 报 0x800f081f
